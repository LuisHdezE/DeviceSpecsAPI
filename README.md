# DeviceSpecsAPI

Microservicio de consulta de especificaciones técnicas de dispositivos móviles, con TypeScript, Fastify y arquitectura hexagonal ligera.

**Estado: planificación y documentación aprobadas; desarrollo y despliegue pendientes.**

Consumidor inicial: administración de [FixPhone](https://github.com/LuisHdezE/FixPhone). Consultar datos no implica guardarlos; únicamente FixPhone podrá hacerlo mediante confirmación explícita. El showroom público queda fuera del alcance.

📚 **[Documentación oficial del proyecto](docs/README.md)**: objetivo, arquitectura, estructura, seguridad, tests, CI/CD, despliegue planificado en Google Cloud Run y decisiones técnicas.

Este repositorio es público: nunca agregar claves, secretos, tokens, ni archivos de entorno con valores reales.
